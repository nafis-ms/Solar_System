# Solar System | A Journey Outward 🌌

An interactive, 3D web application that takes users on a cinematic journey outward from the Sun through all eight major planets in our solar system. Built using **HTML5, CSS3, vanilla JavaScript, and Three.js**, this project combines procedural graphics, dynamic lighting, and step-driven camera navigation.

---

## 🌟 Features

- **Procedural 3D Visuals:** Generates custom textures for each planet in real time, featuring Saturn's rings, dynamic moon orbits, an asteroid belt, a starfield, and animated shooting stars.
- **Cinematic Camera Transitions:** Smooth step-by-step navigation that flies the 3D camera to frame each planet as you travel[cite: 2].
- **Interactive Information Panels:** Displays key astronomical statistics (diameter, orbital period, temperature, moon counts) and facts for all 8 planets[cite: 2].
- **Multi-Input Navigation:** Supports mouse wheel scrolling, touch swipes, arrow keys, and direct dot navigation[cite: 1, 2].
- **Responsive Design:** Dynamic layout and adaptive lighting tinting styled using modern CSS variables[cite: 2, 3].

---

## 🛠️ Built With

- **HTML5** — Document structure and WebGL canvas container
- **CSS3** — Custom properties, CSS Grid/Flexbox, and smooth animations[cite: 1, 3]
- **JavaScript (ES6+)** — Application logic and step-based navigation controls[cite: 1, 2]
- **Three.js (r128)** — 3D WebGL rendering, shaders, materials, and lighting engine[cite: 1, 2]
